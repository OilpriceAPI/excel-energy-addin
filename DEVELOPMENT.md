# Development Guide

This guide is for contributors working on the current OilPrice Excel add-in.
For the smoke-proven Mac preview path, see [CUSTOMER_QUICKSTART.md](CUSTOMER_QUICKSTART.md).
Other install procedures remain internal validation paths until their runtime receipts exist.

## Prerequisites

- Node.js 20.9+
- npm
- Microsoft Excel (for testing)

## Setup

```bash
git clone https://github.com/OilpriceAPI/excel-energy-addin.git
cd excel-energy-addin
npm ci
```

## Development Server

```bash
npm run dev
```

This starts a webpack dev server at `https://localhost:3000`. Reload manually after source changes.

### Self-Signed Certificate

The dev server uses a self-signed HTTPS certificate (required by Office.js). On first run, your browser will show a security warning — click "Advanced" > "Proceed to localhost" to accept it.

To install the certificate system-wide:

```bash
sudo npx office-addin-dev-certs install --machine
```

Certificate files are stored in `~/.office-addin-dev-certs/`.

## Sideloading for Development

### Windows Excel Desktop

Desktop Excel does not load this preview add-in by pasting the hosted manifest URL directly into Excel. Use a trusted shared-folder catalog.

1. Build and validate the add-in:

```bash
npm run build
npx office-addin-manifest validate manifest.xml
```

2. On Windows, open PowerShell as Administrator and run:

```powershell
.\scripts\setup-windows-desktop-sideload.ps1 -ClearOfficeCache
```

3. Restart Excel, then load it from **Insert > My Add-ins > Shared Folder**.

### Production vs Dev Manifest

- `manifest.xml` (root) — points to GitHub Pages (`oilpriceapi.github.io`), used for production preview and AppSource submission
- `dist/manifest.xml` — generated by build from the root manifest

## Deployment

The production add-in is hosted on GitHub Pages at `oilpriceapi.github.io/excel-energy-addin/`.

Pushes to `main` run the test workflow and the GitHub Pages build/deploy workflow.
The root `manifest.xml` points to the deployed GitHub Pages assets.

## Architecture

- **Shared Runtime**: The add-in uses Office.js Shared Runtime so custom functions and the taskpane share state
- **Storage**: API keys are stored in `OfficeRuntime.storage` and never placed in worksheet cells or diagnostics.
- **Refreshable formulas**: `OILPRICE.PRICE`, `INFO`, `STATUS`, `UNIT`, `GET`, and `CODES` recalculate through Excel custom functions.
- **Entitlements**: The add-in does not infer plan names or limits; it renders API auth, entitlement, quota, and rate-limit responses.

## Debugging

1. In Excel on the web, press F12 to open browser dev tools
2. In Excel Desktop, use the "Attach Debugger" option from the add-in menu
3. Select the `oilpriceapi.github.io/excel-energy-addin/` frame in the Console context dropdown
4. Filter Network for `oilprice` before rerunning **Test Key** or a formula
5. Use the task pane's **Refresh** and **Copy Diagnostics** controls; copied diagnostics never include the API key
6. See [EXCEL_SUPPORT_RUNBOOK.md](EXCEL_SUPPORT_RUNBOOK.md) for stage-by-stage interpretation
