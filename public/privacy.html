Privacy Policy

OilPrice Excel Add-in

Last updated: July 19, 2026

The add-in stores an OilPriceAPI key in Office shared runtime storage and sends it to OilPriceAPI only as the authorization header for API requests. The add-in does not read or upload workbook files.

Data used by the add-in

Data Use Handling
API key Authenticate OilPriceAPI requests Stored in OfficeRuntime.storage; removed when the user chooses Clear Key
Formula arguments Build the requested allowlisted API GET Sent to https://api.oilpriceapi.com when Excel recalculates
Runtime diagnostics Troubleshoot auth, network, CORS, timeout, and response errors Stored in Office shared runtime storage; excludes the API key and formula arguments

Data not collected by the add-in

  • Workbook files or worksheet contents
  • API keys in diagnostics, clipboard output, URLs, or analytics
  • Advertising or third-party analytics events

Services

GitHub Pages hosts the static add-in files. OilPriceAPI receives API requests and standard request metadata. OilPriceAPI account and request handling are governed by the OilPriceAPI Privacy Policy. GitHub hosting is governed by the GitHub Privacy Statement.

Control and support

Use Clear Key in the OilPrice pane to remove the stored key. Removing the add-in also stops formula requests. For privacy questions, contact privacy@oilpriceapi.com. For product support, use the Excel support page.
