OilPrice Excel Add-in

Bring latest-available OilPriceAPI records into Excel with worksheet formulas that expose units, source timestamps, and freshness context.

Get an API key Mac preview setup

Formula scope

  • =OILPRICE.PRICE("BRENT_CRUDE_USD")
  • =OILPRICE.INFO("BRENT_CRUDE_USD")
  • =OILPRICE.STATUS("BRENT_CRUDE_USD")
  • =OILPRICE.UNIT("BRENT_CRUDE_USD")
  • =OILPRICE.GET("/v1/prices/latest", "by_code=BRENT_CRUDE_USD")
  • =OILPRICE.CODES()

An OilPriceAPI account and API key are required. Dataset access, endpoint access, quotas, and limits depend on the account. Cadence varies by source, market hours, dataset, and account entitlement.
