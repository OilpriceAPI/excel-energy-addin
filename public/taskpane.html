Formula errors

#AUTH_REQUIRED: save your API key in this pane.

#AUTH_INVALID: check or replace your API key.

#RATE_LIMITED: follow the retry time shown, then retry.

#TIMEOUT: retry once, then check service status.

#UPGRADE_REQUIRED: your plan does not include that endpoint.

#API_ACCESS_SUSPENDED: contact support; replacing the key or upgrading may not restore a suspended account.

#EMAIL_CONFIRMATION_REQUIRED: use the confirmation recovery link shown in the formula error.

#ACCESS_DENIED: run Test Key, then contact support if the reason remains unknown.

#NO_DATA: the API returned no matching data.

#NETWORK_OR_CORS: Excel loaded the add-in, but the browser, CORS, or a network policy blocked the API request.

#OFFLINE: the device reports that it is offline.

#INVALID_RESPONSE: the API responded, but the add-in could not read the payload.

#SERVER_ERROR: OilPriceAPI is temporarily unavailable.

#UNSUPPORTED_ENDPOINT: use a supported endpoint path.
